# 🌍 Data Jobs Survey Analysis – 2025

This project is a data‑driven exploration of job roles, salaries, skills, and satisfaction levels in the data industry, based on a real survey of 612 participants across multiple countries.

## 📊 What’s Inside

- 🔍 Demographic breakdown of data professionals  
- 💼 Salary insights by job title, industry, and country  
- 🧠 Education levels and learning habits  
- 📈 Most in‑demand tools & programming languages  
- 💬 Job satisfaction & work‑life balance analysis  
- 📦 Clean and interactive visualizations (Power BI / Tableau / etc.)  

## 📌 Key Insights

- Python is the #1 language in data roles by far  
- Data Scientists earn the highest average salary, but Data Analysts dominate in numbers  
- Work‑life balance and remote flexibility are top priorities for job seekers  
- Industries like healthcare and finance offer higher pay than tech or telecom  
- Many professionals successfully transitioned into data from other fields  

## 🧠 Goal of the Project

To help:  
- 🧑‍💻 Aspiring data professionals make informed career decisions  
- 🏢 Companies understand what talent values most  
- 📚 Educators/trainers focus on real‑world skills demand  

## 🛠️ Tools Used

- Excel / CSV (raw data)  
- Power BI (for dashboards)
